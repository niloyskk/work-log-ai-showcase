# Work Log AI

**A Flutter app for tracking work hours and earnings, with AI-assisted workflows.**

Independently built by [Md Istain Ahmed](https://www.linkedin.com/in/istain/). Available on iOS and Android.

[Download on the App Store](https://apps.apple.com/us/app/work-log-ai/id6775253552) · [Get it on Google Play](https://play.google.com/store/apps/details?id=com.worklog.ai)

## Product overview

Work Log AI helps users keep work records, track earnings and produce reports in one mobile app.

## Key features

- Work-hour tracking, punch in/out and break management
- Earnings records and work summaries
- AI-assisted schedule scanning
- Invoices and PDF reports
- Cloud backup and multilingual support

## Technology

**Flutter / Dart · Firebase · Google Gemini API**

## My contribution

I developed this application independently, including the mobile experience, Firebase integration, AI integration and store delivery.
